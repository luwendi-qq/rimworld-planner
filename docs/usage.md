# 使用说明

[← 返回 README](../README.md)

## 绘制

- 网格画布，支持缩放（滚轮）、平移（中键 / 空格拖 / Alt 拖）
- 默认地图 **250×250**（和游戏标准地图一致），可在顶部改
- 建筑按正确的**格子占地**摆放，`R` 旋转，占地尺寸随朝向自动变化
- **可选原版贴图**：跑一次 `tools/extract_textures.py` 就显示游戏原版美术
  （墙体连接图集、床/桌朝向、地板材质、按材质染色），没有贴图时自动退回矢量图

### 绘制方式按建筑类型自动切换（和游戏一致，不需要手动设）

| 建筑类型 | 绘制方式 |
| --- | --- |
| 墙 / 栅栏 / 沙袋 | **方框** —— 拖一个矩形只画最外一圈（画房间最快） |
| 门 / 家具 / 生产设施 / 电器 | **直线** —— 点一下放一个 |
| 地面 | **填充** —— 拖一个矩形整片铺满 |

拖动过程中画布正中实时显示 **`宽 × 高`** 和本次将绘制的**格子数**。

### 绘制规则

- **只能拉横线 / 竖线 / 点，不能拉斜线**（和游戏一致）：斜着拖会自动取位移较大的那一轴，
  另一轴锁在起点，不会出现锯齿状斜线；多格建筑（床、桌子…）一次只放一个。
- **不会默默覆盖已有建筑**：直接画在已有建筑上会被挡下来，提示「与某某重合，先删掉那一格」——
  免得手一抖把画好的墙换掉。例外是**贴墙件**（制冷机、壁灯、通风孔）与实体可以同格共存，
  **电缆**也可以埋在墙下（游戏里就是这么放的）。
- **电缆自动衔接**：电线按四周邻居画出连向上/下/左/右的线，而不是固定一个十字；孤立的一格画成接线盒。
- **全中文命名**，和游戏内一致（内置对照表；若提取了官方简中语言包则使用官方名）。
- 框选、多选、拖动移动、复制粘贴、删除、撤销/重做（**框选连地板一起选**，按 `Delete` 一次删掉；拖已选中的东西就是移动）。
- 打开时默认按「看得清网格」的缩放居中（250×250 的空地图不再缩成一片小点）。
- 按分类浏览 + 搜索（中文 / 英文 / id）。

### 物品栏

左侧最前面是两个页签：

- **★ 收藏**：点物品上的 ☆ 收藏，常用的（比如你基地的标配墙和床）放这里，一秒就翻到
- **🕘 最近**：最近用过的建筑自动记下来（本机保存，关掉浏览器也在）

其余页签是建筑分类：结构 / 生产 / 家具 / 电力 / 防卫 / 温度 / 娱乐 / 雕像纪念 / 仪式祭祀 / 丧葬 / 科幻科技 / 杂项 / 地板。

> 少数条目带 **○**：它们不在建筑师菜单里（比如雕塑要在雕塑台上做、虚空电池是任务奖励），
> 但仍然可以规划 / 读存档识别，摆放不受影响。

**鼠标悬停**在物品上能看到完整信息：占地、耗电/发电、美观、**造价**（材料中文名）、**工时**、
**科技前置**、**建造技能**、**耐久**、能不能换材质。

### 地板层

木地板 / 石砖 / 混凝土 / 无菌地板 / 地毯 / 活铁板 / 逆重亚结构 等。
桥在 1.7 里已经是**地形**（从地板菜单造），所以本工具也把它放进了地板层；
Odyssey 的**重型桥**（钢 14，要先研究「重型桥梁」）也在。

地板的造价 / 工时 / 科技 / 建造技能也都在悬停提示里。

### 材质

**材质是逐物品的**（和游戏一样）：在左侧物品栏 **长按左键**（或右键）某个建筑 → 弹出材质菜单
（按木材/石材/金属/纤维/皮革分类，共 53 种，从游戏 defs 提取）→ 选好后放到画布上。
已经放好的可以选中后在右下角批量改。**导入存档时每个建筑的材质会一起带进来。**

## 存档分析（读 .rws 之后）

读取存档后，右侧会多出「存档情报」和「工作量估算」两块：

- **地形层**（快捷键 <kbd>T</kbd>）：把存档里的真实地形画在画布底层，山体/矿石用深色斜纹标出来。
- **按地形校验**：放置时按游戏 `terrainAffordance` 检查。沼泽/软沙只有 `Light`，墙需要 `Heavy`，会被标红；
  水面没有可建造 affordance，要先铺桥；山体/矿石挡路，要先开采。默认只警告（允许先把蓝图画上去），
  勾「严格模式」则直接拒绝放置。
- **标出不可建造**（快捷键 <kbd>B</kbd>）：把当前笔刷放不下的所有格子标红/蓝，一眼看清哪些要开挖、哪些要垫地基。
- **玩家区域**：存档里的 `Area_Home` 会显示成淡绿底 + 边界（右侧「玩家区域」勾选框，快捷键 <kbd>T</kbd> 旁边）。
  它能帮你区分「基地范围」和「地图自带的荒野/山体」。
- **库存范围**：**默认只统计玩家区域内的物品**；勾掉「库存只算玩家区域」就改用全地图（含荒野里散落的物资）。
  工作量估算用的也是同一份库存。
- **存档情报**：殖民者姓名与建造/采矿/智力等级、科技完成度与当前研究、玩家区域/全地图库存（按数量排序）。
- **工作量估算**：可选建造人数/采矿人数/每日工时/搬运开销，点「估算蓝图」得到：
  - 结论：能建 / 有缺口（缺材料或缺科技）/ 暂时建不了（地形或技能挡路）
  - 地形：需要开采的山体格数、撑不住蓝图的格数与原因
  - 科技：缺失的前置（含递归前置）、剩余点数与预计时间
  - 材料：需要 / 库存 / 缺口（逐物品）
  - 工期：建造工时、开采工时、研究工时与合计天数（公式面板里会写清）
- **房间列表**：点任意一个房间条目会直接把视图定位到那个房间。
- **底图锁定**：存档原有建筑默认锁定（淡显 + 左上角 🔒），导出蓝图时自动排除。

> 估算用的数值尽量贴游戏：建造速度 `0.3+0.0875×等级`、开采 `100/MiningSpeed` tick/次（自然岩石 80 伤害一次）、
> 研究 `0.00825×研究速度×研究台系数×难度系数` 点/tick，1 游戏日 = 60000 tick。仍然是估算，请以游戏内为准。

## 界面

**配色和控件观感都取自游戏本体**（不是凭感觉配的）：
- **首次打开会弹窗提示导入游戏资源**（建筑尺寸/造价/地形/贴图更精确）；如果不想每次看到，勾「不再提醒」。
  右侧「导入游戏资源」面板始终保留，随时可以再导入。

- 按钮用游戏那种暖棕 `#6A512E`（悬停 `#886432`／按下 `#624927`，取自 `UI/Widgets/ButtonBG*`）
- 命令按钮用建筑师菜单的深蓝灰 `#395365`（`DesButBG`），次级按钮是暗底细边（游戏里大量用这种）
- 面板底 `#0C0F11`（`TooltipBG`）+ 暗绿灰 `#333F33`（`TexUI.GrayBg`）
- **选中高亮是游戏里的暖黄 `#FFF080`**（`TexUI.HighlightSelectedTex`），强调色用青 `#33CDD9`
- 校验提示用 `ColorLibrary` 里的红/金/绿；UI 文字带一层深色描影（和游戏一致）

其它细节：

- **画布左下角是游戏那种大方块工具条**（放置/框选/橡皮，带图标；框选工具兼移动），选中项描暖黄边
- **分类是连成一排的标签条**（照 `UI/Widgets/TabAtlas`：暗底 + 上缘高光，当前页签带暖黄顶边）
- **物品栏是建筑师菜单式的方格**（深蓝灰渐变 + 上缘高光 + 悬停变亮 + 选中暖黄边）
- **提示框是自己画的**（近黑底 + 细亮边，照 `TooltipBG`），浏览器原生那种灰框看不到了
- 字体用 Arial（游戏 UI 用的就是 Arial，Windows/macOS 都自带；中文走系统字体）
- 顶栏 **? 帮助**：三步上手、绘制规则、材质怎么选、导出路径（按系统自动显示）

## 校验结果

点右侧「**运行校验**」会跑一遍检查，问题按严重程度排出来，点一条就跳到对应位置。

带 **≈** 的是**近似模型**得出的提示（电力连接规则、房间识别、温控估算、作用范围遮挡），
不是游戏里的精确规则；不带的（占地冲突、地形撑不住、边界）是硬规则。
右侧「**显示近似提示（≈）**」可以只看你确定的那部分。

完整清单和算法见 [checks.md](checks.md)。

## 模板

同一个标准卧室要画几十遍是常事。右侧「模板」面板：

1. 框选一块区域（建筑 + 地板一起选）
2. 起个名字（比如「标准卧室」）→ 点「**存为模板**」
3. 之后点一下模板名，就贴到鼠标所在的位置

模板存在本机浏览器里，关掉页面也在。名字重复会覆盖同名模板。

## 房间

右侧「房间」面板里，每个被围出来的区域都会列一行：

```
房间 #1  25 格 · 空间 35（一般）· 门 1 · 需制冷 0/2
角色：卧室  目标 [-10] °C
```

- **房间角色是自动推导的**，和游戏一样由房间里的东西决定（游戏里的 `RoomRoleWorker`）：
  1 张普通床 → 卧室，2 张以上 → 兵营；医疗床 → 病房；囚犯床 → 囚室；
  炉灶 → 厨房；工作台 → 工坊；研究台 → 实验室；餐桌 → 餐厅；娱乐设施 → 娱乐室；
  储物架 → 储藏室；棺材 → 陵墓；动物床 → 畜栏；2 张以上婴儿床 → 育儿室；等等。
  你不需要、也不能手填用途 —— 游戏本身就没有这个开关。
- **床的普通 / 医疗 / 囚犯**：选中床后，右下角「床的用途」可以切换。这会影响房间角色判定
  （对应游戏里床的 Inspector 选项）。普通床切成医疗就变成病房，切成囚犯就变成囚室。
- **目标温度**是本工具的规划参数，不是游戏里的房间属性。默认 21°C，可以按房间改；
  面板顶上的**环境温度**（默认 21°C）用来算要几台制冷机 / 加热器：
  `需要台数 = ceil(面积 × |环境 − 目标| ÷ 630)`（约等于「一台制冷机管 30 格 × 21°C 温差」）。
- 点房间摘要那一行可以把视图跳到那个房间。

> 差距：游戏里「床算不算卧室」还看床的归属 / 恋人 / 孩子，规划器没有小人，只按床数近似；
> 祭坛要求 Ideology 的 meme，规划器只看有没有祭坛；房间是否需要屋顶，只有导入存档时才知道屋顶。
> 这些只影响角色名，不影响占地 / 建造校验。

## 导出

顶栏一排导出按钮：

| 按钮 | 出来的东西 |
| --- | --- |
| **保存工程** | `.rwplan.json`，完整保真（含地形底图、锁定状态、材质记忆、各房间目标温度），之后能再打开继续改 |
| **存入 Blueprints** | 选一次游戏的 Blueprints 文件夹，以后一键把蓝图写进去（需要 Blueprints 模组） |
| **导出蓝图** | Blueprints 模组的真蓝图 `.xml`，带每件建筑的材质与朝向；分类可以在右侧「计划设置」里改 |
| **导出图片** | 把整个布局（自动算包围盒）导出成 PNG |

PNG 导出用的是画布上看到的东西（有原版贴图就是原版贴图，没有就是矢量图），
只导出**全部内容**（所有建筑和地板的包围盒，四周留一点白），
不会带上悬停高亮、框选这些交互提示。画布上没东西时不会导出。

## 自动保存

右侧「本地存档」面板里勾着「**自动保存到浏览器**」时，改完东西过一会儿会自动存一份
（存在本机浏览器里，固定一个存档位，不占「本地存档」列表）。
下次打开如果画布是空的，会自动恢复上次的内容并提示一句。

主动点顶栏「**清空**」会连自动保存一起删掉 —— 不会阴魂不散地弹回来。
不想自动保存就把那个勾去掉。

## 撤销 / 重做

撤销栈记的是**增量**（这次改了什么），不是整张图的快照，
所以 250×250 的大基地铺满地板也不会把内存撑爆 —— 50 步编辑大约 8 KB，
换成全量快照要 15 MB。最多保留 200 步。
