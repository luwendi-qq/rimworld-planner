# 常见问题

[← 返回 README](../README.md)

### 打开后画布上只有灰色形状，没有游戏贴图？

说明 `img/` 贴图不存在，工具自动退回了**代码绘制的矢量图**，功能完全一样。
想要原版贴图，两条路任选：

- 把 **RimWorld 安装目录**拖进右侧「导入游戏资源」（零安装，推荐）
- 或跑 `python tools/extract_textures.py "<游戏目录>"`

详见 [textures.md](textures.md)。

### macOS 上把文件夹拖进网页没反应，或提示「没拿到文件，换个方式再试一次」？

双击打开 html（`file://` 页面）时，浏览器不允许网页读取**拖进来**的文件夹内容，只会掉出一两个假文件，
这是 Chromium 浏览器（Chrome / Edge / 豆包等）在 `file://` 页面上共有的安全限制，不是工具的问题。点面板上的「**选择游戏目录**」/
「**选择模组文件夹**」把文件夹选进来就行（选一次，结果存在浏览器里，下次打开不用再选）。

- macOS 安装目录：`~/Library/Application Support/Steam/steamapps/common/RimWorld`
- 核心贴图不在 `Data/Core/`，在 `RimWorld.app/Contents/MacOS/Assets.zip` —— 选安装目录**整层**，工具会自己进去找
- macOS 的 Mods：`~/Library/Application Support/RimWorld/Mods`；Steam 创意工坊模组在 `…/steamapps/workshop/content/294100/`
- 想长期用、又不想每次点按钮：在仓库目录跑 `python3 -m http.server`，用 `http://localhost:8000` 打开，拖拽就正常了

### 需要联网吗？会上传我的数据吗？

不需要，也不会。全部逻辑跑在本地浏览器里，没有任何网络请求。
导入游戏目录时只读你本机文件。（手机上的「在线试用」版也一样，贴图数据存在你本机 IndexedDB。）

### 点了「保存到浏览器」没反应？

`file://` 协议下部分浏览器（尤其 Firefox）会限制 localStorage。
用顶栏「**保存工程**」导出文件即可，效果一样而且更保险。

### 导入游戏目录后，为什么某些建筑还标着 `?`？

说明这个建筑在你装的那套 DLC 里不存在（或者 1.7 已经移除）。
工具保留内置参考值让你继续用，但会标 `?` 提醒你核对。详见 [data.md](data.md)。

### 导入游戏资源要多久？可以切走标签页吗？

第一次大概几十秒到一两分钟，取决于你装了几个 DLC。
**别切走标签页** —— 浏览器会节流后台页面的任务，切走会明显变慢。结果会存进 IndexedDB，下次打开直接可用。

### 校验结果能信吗？和游戏里对得上吗？

**是近似模型，不是游戏内数值的保证。** 它会算电力组网、房间封闭性、空间评分档位、室外可达性这些
「结构性问题」，用来排查漏了电缆、房间不封闭、冷库制冷不够之类的情况。
具体算法和局限见 [checks.md](checks.md)。

### 校验结果前面的「≈」是什么意思？

标 ≈ 的是**本工具自己的近似模型**得出的（电力连接规则、房间识别、温控估算、作用范围遮挡），
不标的是硬规则（占地冲突、地形撑不住、贴地图边界）。
右侧「显示近似提示（≈）」可以只看你确定的那部分。

### 物品栏里带 ○ 的是什么东西？

它们**不在建筑师菜单里**，但游戏里并非造不出来：比如雕塑要在雕塑台上做、虚空电池是任务奖励。
规划器仍然可以摆放、读存档识别，只是用 ○ 提醒你「不是在建筑师菜单里直接点的」。

### 房间的用途要怎么定？

**不用定，游戏也没有这个开关。** 右侧「房间」面板会按房间里的东西自动推导角色：
1 张普通床 → 卧室，2 张以上 → 兵营，医疗床 → 病房，炉灶 → 厨房，工作台 → 工坊…
床可以在右下角切成普通 / 医疗 / 囚犯，角色会跟着变。
目标温度是本工具的规划参数，不是游戏里的房间属性。
玩家区域外（`Area_Home` 之外）的远古遗迹、废弃营地会标成**地图预制**，不算玩家房间，也不做房间校验。
详见 [usage.md 的「房间」](usage.md#房间)。

### 模板和收藏存在哪？

都存在**你本机的浏览器里**（localStorage），不上传、不同步。
换浏览器或清了浏览器数据就没了 —— 重要的布局记得用顶栏「**保存工程**」导出成文件。

### 自动保存会不会覆盖我手动存的？

不会。自动保存用的是另一个固定的存档位（「（自动保存）」），和你手动存的工程各存各的。
主动点「清空」会把自动保存一起删掉。

### 导出的蓝图在游戏里怎么用？

放进 `Blueprints` 文件夹，游戏里用蓝图按钮载入，工人会消耗材料去建。
需要 **Blueprints** 模组。各平台路径见 [import-export.md](import-export.md)。

### 能规划 mod 的建筑吗？

可以。右侧「导入模组建筑」把模组文件夹拖进来，就会把 mod 新增的可建造建筑和贴图扫进物品栏（多出「🧩 模组」页签）。

- 本地 mod 在 `<游戏目录>/Mods/`；**Steam 创意工坊订阅的在 `steamapps/workshop/content/294100/`**，不是 `Mods/`
- 把整个 `294100` 文件夹拖进来 = 一次导入全部订阅 mod
- 先「导入游戏资源」再导模组：模组的 `ParentName` 常继承原版抽象 def，没核心数据会解析不全
- 只读 `Defs/` 里直接声明的建筑：靠 `Patches/` XML Patch 或 C# 动态加的建筑扫不到；贴图打包在 AssetBundles 里的会退回矢量图标

详见 [import-export.md 的「导入模组建筑」](import-export.md#导入模组建筑)。

### 支持手机吗？

能用，但体验一般 —— 界面按桌面（鼠标 + 键盘快捷键）设计。
「在线试用」版在手机上可以打开看看，正式用建议桌面浏览器。

### 撤销能退多少步？

200 步。撤销记的是**增量**（这次改了什么），不是整张图的快照，
所以 250×250 的大基地铺满地板也不会把内存撑爆。

### 数据是从哪来的？准吗？

内置库是人工整理的参考值。跑一次 `tools/extract_defs.py`（或把游戏目录拖进网页）
就会用游戏 Defs 里的真实数值覆盖它：占地、耗电、造价、工时、科技前置、地基要求、耐久全都有。
详见 [data.md](data.md)。

### 为什么 `img/` 不在仓库里？

因为那是 Ludeon 的美术资源，**不能随工具分发**。
`img/` 和 `js/sprites.js` 已通过 `.gitignore` 排除，需要你在本地从自己购买的游戏里提取。
详见 [textures.md](textures.md#版权)。

### 怎么反馈 bug / 提建议？

到 [Issues](https://github.com/luwendi-qq/rimworld-planner/issues) 提。
如果能附上你的**工程 JSON**（顶栏「保存工程」导出）和截图，定位会快很多。
