Steam 创意工坊的 mod 在哪？

创意工坊订阅的 mod 不在 RimWorld/Mods，而在 Steam 库里的 steamapps/workshop/content/294100/（294100 是 RimWorld 的 AppID）。

  • Windows：C:\Program Files (x86)\Steam\steamapps\workshop\content\294100
  • macOS：~/Library/Application Support/Steam/steamapps/workshop/content/294100
  • Linux：~/.local/share/Steam/steamapps/workshop/content/294100

把整个 294100 文件夹拖进上面的框，就是一次导入全部订阅的 mod（每个子文件夹名就是工坊 ID）。

找不到 Steam 装在哪个盘：Steam 客户端 → 库 → 右键 RimWorld → 管理 → 浏览本地文件，再退回到 steamapps/workshop；换过库位置的，去 Steam 设置 → 存储 里看每个库的路径。

🍎 macOS 提示：双击打开 html（file://）时浏览器会拦住拖进来的文件夹， 请点下面的「选择模组文件夹」按钮。

使用说明

怎么用

  1. 左边点一个建筑或地板，然后在网格上点一下（或拖一个框）画出来。
  2. 点「运行校验」，右侧会列出问题，点问题可以直接跳到对应位置。
  • 墙 / 栅栏 / 沙袋：拖框只画最外一圈，圈房间最快。
  • 门 / 家具 / 电器：点一下放一个，拖动只能拉横线或竖线。
  • 地板：拖框整片铺满。橡皮：拖框整片删除（含地板）。
  • 框选：拖框选中建筑和地板，按 Delete 删除；拖动已选中的东西可以整体移动。
  • 材质：在左边长按左键（或右键）建筑即可选材质（木材 / 石材 / 金属 / 纤维 / 皮革…）； 已经放好的可以选中后在右下角改。

拖动时画布正中会显示宽 × 高和格子数。已经画过的地方再放东西会被挡下来（提示先删掉那一格）， 不会默默覆盖你的规划；电缆可以埋在墙下，制冷机 / 壁灯可以贴在墙上。 风机风区、制冷机冷热端、太阳灯照射圈这类作用范围，摆放时就能看到。 想下次接着改，点「保存工程」存成 .rwplan.json 即可（默认也会自动存一份到浏览器）。

房间、模板与物品栏

  • 房间角色：右侧「房间」面板会按房间里的东西自动推导角色 （1 张普通床 = 卧室，2 张以上 = 兵营，炉灶 = 厨房，工作台 = 工坊…）。 游戏里没有「手填房间用途」这回事。床可以在右下角切成普通 / 医疗 / 囚犯。 每个房间还可以单独设目标温度，用来估算要几台制冷机 —— 面板顶上的环境温度也可以改。
  • 模板：框选一块区域 → 右侧「模板」面板起个名字 → 「存为模板」； 之后点一下模板名，再点画布就贴在那里（右键取消）。同一个标准卧室不用画几十遍。
  • 收藏 / 最近：物品栏最前面两个页签。点物品上的 ☆ 收藏，常用的放这里。
  • 悬停：鼠标停在物品上能看到造价、工时、科技前置、建造技能、耐久。

校验结果里带 ≈ 的是本工具的近似模型（电力组网、房间识别、温控估算）， 不带的才是硬规则；右侧可以只看你确定的那部分。

导回游戏：蓝图

点顶栏「导出蓝图」得到一个 .xml，放进游戏的 Blueprints 文件夹， 游戏里载入蓝图后，小人就会消耗材料开建。需要 Blueprints 模组（1.7 用这个，另需 1.7 版 Harmony）：

模组工坊 ID
Blueprints - 1.7 Waylith (Unofficial) 3819556044

Blueprints 文件夹在哪

和存档在同一层，游戏里 选项 → 常规 → 打开存档数据文件夹 就能看到：

<存档数据目录>/
├── Saves/        ← 存档 .rws 在这里
├── Config/
└── Blueprints/   ← 导出的 .xml 放这里

顶栏点「存入 Blueprints」选一次文件夹，之后一键写入，不用管路径。

读取存档当底图

「读取存档 .rws」会把已经建好的基地读进来（含每件物品用的材质），在它上面继续规划。 只读取位置、朝向和材质，不会改动存档；地图尺寸会自动跟随存档。

数据与贴图

右侧「导入游戏资源」把 RimWorld 安装目录拖进去（或点「选择游戏目录」）， 工具会读取建筑数据与原版贴图并缓存在本机，下次打开直接可用。 不导入也能用，会自动使用内置的矢量图。

贴图是游戏的美术资源，本工具不附带，只在你本机从你购买的游戏里读取。

导入一次游戏资源？

把 RimWorld 安装目录导入后，工具会读取：

  • 精确的建筑尺寸 / 耗电 / 造价 / 工时 / 科技前置
  • 地形与可建造性、地图自带山体识别
  • 原版建筑贴图（只从你本机的游戏读取，不上传）

不导入也能用：会自动使用内置数据和矢量图，只是部分数值是参考值。右侧「导入游戏资源」面板一直保留，可以随时再导。
